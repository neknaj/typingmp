# アプリケーション動作リファレンス

---

## 画面構成（タイピング画面）

```
┌────────────────────────────────────────┐
│           タイトル（問題名）            │
│                                        │
│   [前の行（薄く表示）]                  │
│                                        │
│   上段: 目標テキスト（ルビ付き）         │
│   下段: 入力テキスト（正誤表示）         │
│                                        │
│   [次の行（薄く表示）]                  │
│                                        │
│  Progress: 1/10  Speed: 3.5 KPS       │
│  Accuracy: 98.5%  Misses: 1           │
│  Time: 00:12.34                       │
│ ████████░░░░░░░░░░░░  ← 進捗バー      │
└────────────────────────────────────────┘
```

### 上段（目標テキスト）

- 漢字などの base テキストを表示
- ルビ（読み仮名）は base テキストの上部に小さく表示
- anno の annotation は base テキストの下部に小さく表示
- 色の意味:
  - **ACTIVE**: 現在入力中のセグメント（明るい色）
  - **CORRECT**: 入力済み、正解
  - **INCORRECT**: 入力済み、ミスあり
  - **PENDING**: 未入力

### 下段（入力テキスト）

- ひらがな/カタカナの reading テキストを表示
- カーソル位置を示すカーソル記号
- 未確定ローマ字入力（例: 「sh」まで入力した状態）
- 直前の誤入力キーを表示

---

## タイピングルール

### ローマ字入力

ひらがな/カタカナはローマ字で入力します。複数の入力方法に対応しています。

| 文字 | 入力方法の例 |
|------|------------|
| あ | a |
| か | ka, ca |
| し | shi, si |
| ん | nn, n（次が子音の場合） |
| っ | 子音を二重に（kk→っk） |

### 単語単位の進行

- タイピングは単語（Word）単位で管理されます
- 1つの単語内のセグメント（`[ruby]`, プレーンテキスト, `{anno}`）は連続してタイプします
- 単語を完了すると次の単語に進みます
- 行を完了すると次の行に進みます

### 正誤判定

- 各文字は **Correct** / **Incorrect** / **Pending** の状態を持ちます
- 誤入力しても次のキーを正しく入力すれば進めます
- ただし誤入力は Incorrect として記録され、正確率に影響します

## 画面遷移

```
[スタート画面]
     ↓ 問題を選択
[タイピング画面]
     ↓ 全行完了
[リザルト画面]
     ↓ Enterキー
[スタート画面]
```

## スクロール

- 現在の行が長い場合、カーソルが画面中央に来るよう自動スクロールします
- スクロールはフレームレートに依存しない滑らかな補間で行われます
- 新しい行の開始時、テキストは画面右端からスライドインします

## プラットフォーム別の操作

### GUI（minifb）

| 操作 | キー |
|------|------|
| 文字入力 | 通常のキー |
| フォント変更 | Settings の font picker |

### TUI（端末）

| 操作 | キー |
|------|------|
| 文字入力 | 通常のキー |
| レンダリングモード切替 | Tab |
| 終了 | Esc |

レンダリングモード:
- **SimpleText**: プレーンテキスト
- **AsciiArt**: ASCII アートスタイル
- **Braille**: Unicode ブレイル（高解像度風）

### WASM（ブラウザ）

- 通常のキーボード入力
- IME Input 設定は既定で disabled
- disabled のとき printable key は `keydown` で処理し、非表示の `<input>` と OS スクリーンキーボードは使わない
- enabled のときだけ非表示の `<input>` 経由で IME 入力を受け付け、OS / app keyboard の入力ソース切替を許可する

### UEFI（ベアメタル）

- UEFI キーボードドライバを使用
- グラフィックス出力プロトコル（GOP）でピクセル描画

## メトリクス計算

### 速度（KPS: Keys Per Second）

```
KPS = タイプ数 / 総時間（秒）
```

最初のキー入力から最後のキー入力までの時間を使用します。
1秒以上の入力の間隔はセッション区切りとして扱います。

### 正確率（Accuracy）

```
Accuracy = 正解数 / (正解数 + ミス数)
```
