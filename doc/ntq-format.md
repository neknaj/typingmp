# .ntq ファイル形式リファレンス

.ntq ファイルはタイピング問題を定義するテキストファイルです。
UTF-8 エンコーディングで記述します。

---

## ファイル構造

```
#title <タイトル行>
<本文行1>
<本文行2>
...
```

- 1行目は必ず `#title` で始めます
- `#title` に続くテキストはタイトルとして表示されます（本文と同じ記法が使えます）
- 空行は無視されます

---

## セグメント記法

### ルビ記法（ruby）: `[base/reading]`

#### Chinese pinyin ruby

Chinese pinyin readings must be written with numbered tones in problem files.

```
[有/you3]
[春晓/chun1xiao3]
```

Marked-tone pinyin such as `[有/yǒu]` is a parse/lint error. The upper typing prompt keeps the numbered reading (`you3`), and completed lower ruby is displayed with tone marks (`yǒu`). Bopomofo readings are treated as Traditional Chinese and are not converted by this pinyin display rule.

読み仮名（ルビ）を付ける記法です。ユーザーは `reading` をタイプします。

```
[秋/あき]       → 「秋」と表示し、ユーザーは「あき」をタイプ
[Rust/ラスト]   → 「Rust」と表示し、ユーザーは「ラスト」をタイプ
```

- `base`: 画面に表示されるテキスト
- `reading`: ユーザーがタイプする読み。日本語かな、数字声調付きpinyin、注音符号、直接入力する英字などを指定できます
- ルビは base テキストの上部に小さく表示されます

### アノテーション記法（anno）: `{inner/annotation}`

補足情報を付ける記法です。ユーザーは `inner` の内容をタイプします。`annotation` は画面下部に補足として表示されるだけでタイプ不要です。

```
{[微分/びぶん][係数/けいすう]/derivative}
→ 「微分係数」と表示し、ユーザーは「びぶんけいすう」をタイプ
→ 「derivative」が補足として画面下に表示
```

- `inner`: ruby 記法やプレーンテキストを含む入力対象テキスト
- `annotation`: 翻訳・注釈などの補足情報（表示専用、タイプ不要）
- `inner` には `[ruby]` とプレーンテキストを混在させられます

```
{[台湾/たいわん]の[首都/しゅと]/Taiwan's capital}
→ inner: [台湾/たいわん]の[首都/しゅと]
→ ユーザーは「たいわんのしゅと」をタイプ
→ 「Taiwan's capital」が補足表示
```

## 単語境界の制御

複数のセグメントをまとめて1つの「単語」として扱う場合や、単語を分割する場合に使います。

### ハイフン `-` による連結

隣接するセグメントを連結して1単語にします。

```
[悲/かな]-しき
→ [Annotated(悲,かな), Plain(しき)] が1単語
→ ユーザーは「かなしき」を連続してタイプ

ふみ-[分/わ]-け
→ [Plain(ふみ), Annotated(分,わ), Plain(け)] が1単語
→ ユーザーは「ふみわけ」をタイプ
```

**前後どちらかにセグメントがない場合**、ハイフンは連結子にならず「-」という独立した単語になります。

```
[東京/とうきょう]/-/[大阪/おおさか]
→ 3つの単語: Annotated(東京,とうきょう), Plain(-), Annotated(大阪,おおさか)
```

anno セグメントもハイフンで連結できます：

```
{[悲/かな]/sad}-しき
→ [Anno{inner:[Annotated(悲,かな)],annotation:"sad"}, Plain(しき)] が1単語
```

### スラッシュ `/` による分割

セグメントを別の単語として分割します。

```
とま/を/あらみ
→ 3つの単語: Plain(とま), Plain(を), Plain(あらみ)
```

**注意**: `[base/reading]` や `{inner/annotation}` の括弧内の `/` は単語区切りとして機能しません。括弧の外側の `/` のみが単語区切りになります。

### スペース ` ` による分割

スペースは分割を行い、さらに「スペース文字そのもの」を独立した単語として挿入します。

```
[春/はる] [夏/なつ]
→ 3つの単語: Annotated(春,はる), Plain(" "), Annotated(夏,なつ)
```

## エスケープ

バックスラッシュ `\` で次の文字をエスケープできます。特殊文字をテキストとして使いたい場合に使います。

```
\[   → 「[」をそのまま表示（ruby 開始とみなさない）
\]   → 「]」をそのまま表示
\{   → 「{」をそのまま表示
\}   → 「}」をそのまま表示
\/   → 「/」をそのまま表示（単語区切りにならない）
\-   → 「-」をそのまま表示（連結子にならない）
\\   → 「\」をそのまま表示
```

---

## サポートしない記法

以下の gloss 記法はサポートしません：

- **nest**: `---` / `;;;`（セクション区切り）
- **katex**: `$...$` / `$$...$$`（数式）

## 記述例

```
#title [小倉/おぐら][百人一首/ひゃくにんいっしゅ]
[秋/あき]の[田/た]の/かりほ/の[庵/いほ]の/とま/を/あらみ/わ/が[衣手/ころもで]は[露/つゆ]に/ぬれ/つつ
[春/はる][過/す]-ぎ/て[夏/なつ][来/き]に/けら/し[白妙/しろたへ]の[衣/ころも]ほす/てふ[天/あま]-の-[香具山/かぐやま]
```

```
#title {[微分/びぶん][方程式/ほうていしき]/Differential Equations} の[練習/れんしゅう]
{[微分/びぶん][係数/けいすう]/derivative}を[求/もと]-める
```
